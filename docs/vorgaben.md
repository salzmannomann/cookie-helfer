# Vorgaben (festgelegt am 11.10.2026)

| Frage | Entscheidung |
|---|---|
| Unbedingt notwendige Cookies | immer erlaubt |
| Funktionale / Präferenz-Cookies | erlaubt |
| Statistik / Reichweitenmessung | nein |
| Personalisierte Werbung, Profilbildung, Partner | nein |
| „Berechtigtes Interesse“-Schalter | alle ausschalten |
| „Zustimmen oder bezahlen“ (Pur-Abo, contentpass …) | **zustimmen**, nie bezahlen, nie Abo-Knöpfe |
| Unbekanntes Banner, KI unsicher | nichts klicken, nur Hinweis im Popup |
| Ausnahmen je Seite | im Popup einstellbar, wird gemerkt |
